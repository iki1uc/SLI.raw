# SLI.raw — Axiom C SLI ist das dritte Axiom: A = VADER (FORK) B = MAAT (WORK) C = SLI (wLOCH) SLI nutzt WORK und FORK gleichzeitig, aber sortiert, beschleunigt und messbar. SLI besitzt: - IX (Eingang) - XI (Ausgang) - BOOST (Beschleuniger) - wLOCH (Kontaktpunkt) SLI ist der einzige Zustand, in dem WORK und FORK gleichzeitig wahr sind.
